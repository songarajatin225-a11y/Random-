# Your photos go here

Drop your pictures into this folder using these names (JPG or PNG):

```
sister1.jpg   sister2.jpg
memory1.jpg   memory2.jpg   memory3.jpg
family.jpg    rakhi.jpg
photo1.jpg    photo2.jpg    photo3.jpg
```

Anything that isn't here yet shows an elegant placeholder instead — the site
never breaks and never substitutes stock photography.

To use different filenames, captions or more/fewer photos, edit the
`memories` array in `src/data/siteConfig.js`.

**Tip:** resize photos to roughly 1600px on the long edge before adding them.
It keeps the site fast on mobile.
